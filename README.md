# 세이프킥 – 헬멧 착용 AI 인증 킥보드 대여 시뮬레이터

전동킥보드를 빌릴 때와 타는 동안 **AI가 카메라로 헬멧 착용을 확인**하는 기능을, 실제 대여 앱처럼 체험해 볼 수 있게 만든 웹 시제품입니다.

👉 **바로 써 보기: https://wogml-07.github.io/safekick-helmet/**
(설치·로그인 없이 휴대폰이나 컴퓨터 브라우저에서 열립니다)

---

## 왜 만들었나요

- 전동킥보드 사고는 **헬멧을 쓰지 않았을 때 피해가 훨씬 심각**해집니다.
- 지금의 대여 과정에는 헬멧을 썼는지 **확인하거나 강제하는 장치가 없습니다.**
- 그래서 "헬멧을 써야만 출발할 수 있고, 주행 중에 벗으면 시동이 꺼지는" 구조를 제안하고, 그 모습을 직접 보여 주기 위해 이 시제품을 만들었습니다.

> 이 시제품은 실제 킥보드와 연결되지 않습니다. 대여 업체 앱에 들어갈 기능을 화면으로 흉내 낸 시뮬레이션입니다.

---

## 어떻게 동작하나요

```
① 킥보드 고르기
   ↓
② 킥보드 정보 확인 → [대여하기]
   ↓
③ 헬멧 인증 안내
   ↓
④ 카메라로 헬멧 착용 확인
   ├ 성공 → ⑤-1 잠금 해제
   └ 실패 → ⑤-2 다시 인증
   ↓
⑥ 주행 중에도 카메라로 계속 확인
   ├ 헬멧을 벗으면 → 경고 → 시동 꺼짐
   └ 다시 쓰면 → 시동 다시 켜짐
   ↓
⑦ 반납 (이용 시간, 요금, 헬멧 경고 횟수 표시)
```

### 판단 기준

| 상황 | 기준 |
|---|---|
| 착용으로 인정 | AI가 판단한 "헬멧 착용" 확률(최근 약 0.4초 평균)이 **70% 이상** |
| 대여 전 인증 통과 | 착용 상태가 **3초** 연속 유지 |
| 대여 전 인증 실패 | **1분** 안에 통과하지 못함 |
| 주행 중 경고 시작 | 헬멧이 **2초** 연속 보이지 않음 (잠깐 가려진 것은 무시) |
| 시동 꺼짐 | 경고 후 **10초** 안에 다시 쓰지 않음 |
| 시동 다시 켜짐 | 헬멧을 다시 쓰고 **3초** 유지 |

---

## 써 보는 방법

1. 위 링크를 엽니다.
2. 킥보드를 고르고 **[대여하기] → [인증 시작]** 을 누릅니다.
3. 안내 화면이 뜨는 동안 카메라 사용을 묻는 창이 나오면 **[허용]** 을 누릅니다. (인증을 빨리 시작하려고 이때 카메라를 미리 켭니다)
4. 헬멧을 쓰고 카메라를 정면으로 바라봅니다.
5. 주행 화면에서 헬멧을 벗어 보면 경고 → 시동 꺼짐이, 다시 쓰면 재시동이 일어납니다.

> 카메라 영상은 서버로 보내지지 않고, 사용자의 휴대폰·컴퓨터 브라우저 안에서만 판단합니다.

**카메라가 안 켜질 때**
- 주소창 왼쪽 자물쇠(또는 ⓘ) 아이콘에서 카메라를 **허용**으로 바꾸고 새로고침합니다.
- 카메라를 쓰고 있는 다른 탭(예: Teachable Machine)이나 프로그램(줌, 카카오톡 등)을 닫습니다. 카메라는 한 곳에서만 쓸 수 있습니다.

### 개발자 모드

시작 화면 아래의 **개발자 모드** 스위치를 켜면 카메라와 AI를 쓰지 않고, 인증·주행 화면의 **[헬멧 쓴 상태] / [헬멧 벗은 상태]** 버튼으로 착용 여부를 흉내 낼 수 있습니다. 헬멧이 없을 때나 발표 중에 전체 흐름(인증 통과 → 경고 → 시동 꺼짐 → 재시동)을 안정적으로 보여 주기 위한 기능입니다. 새로고침하면 꺼집니다.

## AI 모델은 어떻게 학습시켰나요

[Teachable Machine](https://teachablemachine.withgoogle.com/)의 **이미지 프로젝트(표준 이미지 모델)** 로, 팀원이 웹캠으로 직접 찍은 사진을 학습시켰습니다. 실제 앱처럼 **휴대폰 앞 카메라로 얼굴을 정면으로 비추는 구도**에 맞췄습니다.

| 클래스 | 사진 수 | 내용 |
|---|---|---|
| 헬멧 착용 | 600장 | 헬멧을 쓰고 카메라를 바라보는 모습 |
| 헬멧 미착용 | 600장 | 맨머리, 모자, 후드, **헬멧을 손에 들고 있는 모습** |

처음에는 각 150장으로 학습했고, 실제 앱에서 헬멧을 써도 착용 확률이 낮게 나오는 문제가 있어 사진을 각 600장으로 늘려 다시 학습시켰습니다.

두 클래스 모두 아래 조건을 똑같이 맞춰 찍었습니다. 배경이나 조명이 아니라 "헬멧을 썼는지"만 보고 구분하게 하기 위해서입니다.

- 가까이 / 팔 뻗은 거리
- 정면 / 고개를 살짝 좌우·위아래로 돌린 모습
- 서로 다른 장소와 조명

"헬멧을 손에 든 모습"을 미착용에 넣은 이유는, 화면에 헬멧이 보이기만 해도 착용으로 잘못 판단하는 것을 막기 위해서입니다.

## 사용한 기술

| 구분 | 내용 |
|---|---|
| AI 모델 | [Teachable Machine](https://teachablemachine.withgoogle.com/) (이미지 분류: 헬멧 착용 / 헬멧 미착용) |

| 파일 | 역할 |

| `index.html` | 화면의 뼈대 (①~⑦ 화면) |

| `script.js` | 동작 (화면 넘기기, 카메라, AI 판단, 경고·시동 꺼짐) |

## AI 모델 바꾸기

모델을 다시 학습시켰다면 `script.js` 맨 위의 두 줄만 바꾸면 됩니다.

```js
// Teachable Machine에서 [모델 내보내기] → [Tensorflow.js] → [모델 업로드] 후 받은 링크
const MODEL_URL = "https://teachablemachine.withgoogle.com/models/내모델주소/";

// Teachable Machine에서 정한 클래스 이름과 똑같이
const HELMET_CLASS = "헬멧 착용";
```

`MODEL_URL`을 비워 두면 개발자 모드로만 동작합니다. 판단 기준(70%, 3초, 제한 시간 등)도 같은 위치에서 숫자만 바꿔 조절할 수 있습니다.

> 모델을 다시 학습시켰다면 Teachable Machine의 [모델 내보내기] → [Tensorflow.js] 화면에서 **[Update my cloud model]** 을 눌러야 같은 링크의 모델이 새것으로 바뀝니다. 링크만 복사하면 예전 모델이 그대로 쓰입니다.
