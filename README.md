# 세이프킥 – 헬멧 착용 AI 인증 킥보드 대여 시뮬레이터

전동킥보드를 빌릴 때와 타는 동안 **AI가 카메라로 헬멧 착용을 확인**하는 기능을, 실제 대여 앱처럼 체험해 볼 수 있게 만든 웹 시제품입니다.

👉 **바로 써 보기: https://wogml-07.github.io/safekick-helmet/**
(설치·로그인 없이 휴대폰이나 컴퓨터 브라우저에서 열립니다)

---

## 왜 만들었나요

- 전동킥보드 사고는 **헬멧을 쓰지 않았을 때 피해가 훨씬 심각**해집니다.
- 지금의 대여 과정에는 헬멧을 썼는지 **확인하거나 강제하는 장치가 없습니다.**
- 그래서 "헬멧을 써야만 출발할 수 있고, 주행 중에 벗으면 시동이 꺼지는" 구조를 제안하고, 그 모습을 직접 보여 주기 위해 이 시제품을 만들었습니다.

> 이 시제품은 실제 킥보드와 연결되지 않습니다. 대여 업체 앱에 들어갈 기능을 화면으로 흉내 낸 시뮬레이션입니다.

---

## 어떻게 동작하나요

```
① 킥보드 고르기
   ↓
② 킥보드 정보 확인 → [대여하기]
   ↓
③ 헬멧 인증 안내
   ↓
④ 카메라로 헬멧 착용 확인
   ├ 성공 → ⑤-1 잠금 해제
   └ 실패 → ⑤-2 다시 인증
   ↓
⑥ 주행 중에도 카메라로 계속 확인
   ├ 헬멧을 벗으면 → 경고 → 시동 꺼짐
   └ 다시 쓰면 → 시동 다시 켜짐
   ↓
⑦ 반납 (이용 시간, 요금, 헬멧 경고 횟수 표시)
```

### 판단 기준

| 상황 | 기준 |
|---|---|
| 착용으로 인정 | AI가 판단한 "헬멧 착용" 확률이 **80% 이상** |
| 대여 전 인증 통과 | 착용 상태가 **3초** 연속 유지 |
| 대여 전 인증 실패 | **20초** 안에 통과하지 못함 |
| 주행 중 경고 시작 | 헬멧이 **2초** 연속 보이지 않음 (잠깐 가려진 것은 무시) |
| 시동 꺼짐 | 경고 후 **10초** 안에 다시 쓰지 않음 |
| 시동 다시 켜짐 | 헬멧을 다시 쓰고 **3초** 유지 |

---

## 써 보는 방법

1. 위 링크를 엽니다.
2. 킥보드를 고르고 **[대여하기] → [인증 시작]** 을 누릅니다.
3. 카메라 사용을 묻는 창이 뜨면 **[허용]** 을 누릅니다.
4. 헬멧을 쓰고 카메라를 정면으로 바라봅니다.

**시연 모드**: AI 모델이 연결되지 않은 상태에서는 카메라 대신 그림이 나오고, **[헬멧 쓴 상태] / [헬멧 벗은 상태]** 버튼으로 착용 여부를 흉내 낼 수 있습니다. 헬멧이 없어도 전체 흐름을 확인할 수 있습니다.

## 사용한 기술

| 구분 | 내용 |
|---|---|
| AI 모델 | [Teachable Machine](https://teachablemachine.withgoogle.com/) (이미지 분류: 헬멧 착용 / 헬멧 미착용) |
| AI 실행 | TensorFlow.js – 서버 없이 사용자의 브라우저 안에서 바로 판단 |
| 화면 | HTML, CSS, JavaScript |
| 배포 | GitHub Pages |

### 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면의 뼈대 (①~⑦ 화면) |
| `style.css` | 화면 꾸미기 (색, 크기, 배치) |
| `script.js` | 동작 (화면 넘기기, 카메라, AI 판단, 경고·시동 꺼짐) |

---

## AI 모델 연결하기

`script.js` 맨 위의 두 줄만 바꾸면 됩니다.

```js
// Teachable Machine에서 [모델 내보내기] → [Tensorflow.js] → [모델 업로드] 후 받은 링크
const MODEL_URL = "https://teachablemachine.withgoogle.com/models/내모델주소/";

// Teachable Machine에서 정한 클래스 이름과 똑같이
const HELMET_CLASS = "헬멧 착용";
```

`MODEL_URL`을 비워 두면 시연 모드로 동작합니다. 판단 기준(80%, 3초 등)도 같은 위치에서 숫자만 바꿔 조절할 수 있습니다.
